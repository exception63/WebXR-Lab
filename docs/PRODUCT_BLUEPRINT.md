# 产品蓝图

## 一句话定义

WebXR-Lab 是一座“可以亲手进入的空间网页博物馆”：每个房间用一个短而强的体验，展示 WebXR、混合现实和空间网页的一种独特可能性。

## 体验目标

用户第一次进入后的十分钟内，应清楚感受到：

1. 网页可以成为真正的六自由度空间，而不是贴在眼前的平面。
2. 双手、凝视与捏合可以形成自然、低学习成本的输入。
3. 同一网页可针对 Quest 与 Vision Pro 的不同能力渐进增强。
4. 视觉、音频、物理、空间 UI 与协作可以组合成完整体验。
5. 无需安装原生应用，也无需远程云服务即可运行核心体验。

## 产品支柱

### 1. 惊奇
每个展项只表达一个鲜明想法，目标是让用户在 30 秒内理解、在 3 分钟内玩出变化。

### 2. 可触摸
展项不做被动 360° 展示。进入后很快就应出现可以指、碰、抓、捏、拉、组合或改变的对象。

### 3. 跨设备诚实
共同能力保持统一体验语义，设备独有能力明确标记为增强项。任何不支持的能力都在进入前说明。

### 4. 舒适
默认不强迫移动、不操控用户相机、不突然改变尺度。移动展项提供传送、转向和随时退出。

### 5. 可扩展
每个展项是独立模块，有自己的能力需求、资源预算、生命周期、测试记录和降级说明。

## 空间结构

### 桌面入口
- 设备诊断与兼容性结果
- 展项目录、视频/图片预览与说明
- “进入 VR”“进入 MR”“进入空间环境”按钮
- Mac 本地服务状态、版本号与真机报告导出

### 沉浸式 Hub
- 中央为“能力核心”，显示当前设备已启用的输入和会话特性。
- 周围是短距离可达的展项门户，不要求连续摇杆移动。
- 门户颜色表达类型：视觉、交互、物理、音频、MR、空间网页、协作。
- 每个门户显示预计时长、舒适度、所需空间与设备兼容性。
- 任一展项都可通过统一手势或腕部菜单返回 Hub。

## 首个垂直切片

首轮不是追求展项数量，而是一次打穿架构风险：

1. 桌面诊断页和可导出的设备能力报告。
2. Hub + 统一返回机制。
3. 手势序章，验证两台设备输入适配。
4. 光之织机，验证渲染与手部驱动。
5. 动力工坊，验证抓取生命周期与性能。
6. Quest 的最小 passthrough MR 实验台。
7. Vision Pro 27 的最小 `<model>` 空间布景。

## 非目标

- 首版不追求大型开放世界、长剧情或复杂账户系统。
- 不将原生 Quest / visionOS SDK 能力宣传为 Web 能力。
- 不要求两台设备所有展项完全相同。
- 不在首版依赖公网、云数据库、登录、支付或远程分析服务。
- 不以控制器作为唯一交互；控制器是 Quest 的兼容输入之一。
- 不把实验性 WebGPU 沉浸式渲染作为共同基线，首版以 WebGL2 为基线。

## 成功指标

- 新用户不看说明即可在 60 秒内完成第一次选择与抓取。
- 两台目标设备均能进入共同层的 Hub 和至少三个展项。
- 用户可随时在两步以内回到 Hub 或退出沉浸模式。
- 真机运行中不因输入源索引变化、手部暂时丢失或模式切换而卡死。
- Quest 共同展项达到持续 72 FPS 目标；Vision Pro 按浏览器提供的刷新预算达标。
- 断开互联网但保留本地 Wi‑Fi 后，已部署的核心体验仍可使用。
